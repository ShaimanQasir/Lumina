# Video Intelligence API documentation 
[Read product documentation](https://docs.cloud.google.com/video-intelligence/docs/features)
The Video Intelligence API allows developers to use Google video analysis technology as part of their applications. The REST API enables users to annotate videos stored locally or in [Cloud Storage](https://docs.cloud.google.com/storage), or live-streamed, with contextual information at the level of the entire video, per segment, per shot, and per frame. 
[Go to the Video Intelligence API product page for more.](https://cloud.google.com/video-intelligence/)
