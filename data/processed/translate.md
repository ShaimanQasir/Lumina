# Cloud Translation documentation 
[Read product documentation](https://docs.cloud.google.com/translate/docs/overview)
Cloud Translation can dynamically translate text between thousands of language pairs. Cloud Translation lets websites and programs programmatically integrate with the translation service. 
Cloud Translation is offered in two [editions](https://docs.cloud.google.com/translate/docs/editions) (Basic and Advanced) with their own pricing plans. 
[Go to the Cloud Translation product page for more.](https://cloud.google.com/translate/)
